# 🧮 Python Scientific Calculator

A Python-based calculator project featuring a graphical user interface and separate modules for mathematical operations, scientific calculations, conversions, equations, matrices, statistics, and calculation utilities.

The project demonstrates Python programming, GUI development, modular code organization, and the use of built-in and third-party libraries.

## ✨ Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- **Scientific Calculations:** Scientific functions provided by the scientific module.
- **Unit Conversions:** Conversion functionality organized in a separate module.
- **Equation Operations:** Equation-related functionality.
- **Matrix Operations:** Matrix-related calculations.
- **Statistics:** Statistical calculations.
- **Calculation History:** History functionality for calculations.
- **Memory Support:** Calculator memory utilities.
- **Themes:** Separate theme configuration and styling.
- **Graphical Interface:** A desktop interface built with Python GUI tools.

*Available operations depend on the implementation in each module.*

## 🛠️ Tech Stack

- **Language:** Python 3
- **GUI:** Tkinter, if used by the current interface
- **Dependencies:** See `requirements.txt`

## 🚀 Getting Started

### Prerequisites

- Python 3 installed
- pip, Python's package installer

### 1. Clone the repository

```bash
git clone https://github.com/priyanshu2734/calculator.git
cd calculator
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

If the project has no external dependencies, this step may not install anything.

### 3. Run the application

```bash
python main.py
```

Use the graphical interface to perform calculations and explore the operations supported by the application.
